# Automation Testing Project - Selenium & Java

ეს პროექტი წარმოადგენს Selenium WebDriver-სა და Java-ზე აგებულ ავტომატიზებულ ტესტებს.

## შენიშვნები და ტესტირების თავისებურებები (Notes & Findings)

* **ნეგატიური ქეისების არარსებობა:** 
  ტესტებში არ არის შეყვანილი ისეთი ნეგატიური ქეისები, როგორებიცაა ზედმეტად გრძელი ტექსტი (Long Text) ან მხოლოდ სპეციალური სიმბოლოები (Special Characters). აღნიშნული გამოსაცდელ ინფუთში არ საჭიროებს შემოწმებას, რადგან ველს **არ გააჩნია სიმბოლოების რაოდენობის ლიმიტი** ან **სიმბოლოების ფილტრაციის/ვალიდაციის მექანიზმი**.

* **მეგრული და სვანური ენის ფილტრები:** 
  პროდუქტში ამ ეტაპზე ვერ მოიძებნა მეგრული და სვანური ენების ფილტრები. 

* **LoginDataProvider-ის გაფართოება:** 
  არსებობს ცალკე `LoginDataProvider` ფაილი, საიდანაც გენერირდება მეგრული და სვანური ენის ტექსტები. საჭიროების შემთხვევაში, შესაძლებელია ამ მონაცემების ტესტებში მარტივად დამატება და ინტეგრაცია.
