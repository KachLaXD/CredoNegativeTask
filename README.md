

## შენიშვნა

* **ნეგატიური ქეისების:** 
  ტესტებში არ არის შეყვანილი ისეთი ნეგატიური ქეისები, როგორებიცაა ზედმეტად გრძელი ტექსტი ან მხოლოდ სპეციალური სიმბოლოები. აღნიშნული გამოსაცდელ ინფუთში არ საჭიროებს შემოწმებას, რადგან ველს არ გააჩნია სიმბოლოების რაოდენობის ლიმიტი ან სიმბოლოების ფილტრაცია.

* **მეგრული და სვანური ენის ფილტრები:** 
  პროდუქტში ამ ეტაპზე ვერ მოვძებნე მეგრული და სვანური ენების ფილტრები. 

* **LoginDataProvider:** 
  მაქვს ცალკე `LoginDataProvider` ფაილი, საიდანაც გენერირდება მეგრული და სვანური ენის ტექსტები. საჭიროების შემთხვევაში, შემიძლია გამოვაგზავნო განახლებული ფაილი.
